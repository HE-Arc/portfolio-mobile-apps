Reflex Arc est un projet Flutter centré sur la qualité d'interaction mobile, avec une interface fluide, une navigation soignée et une expérience utilisateur réactive.

Ce projet explore un besoin fondamental du développement mobile : concevoir une application simple à comprendre, agréable à utiliser et suffisamment propre techniquement pour évoluer sans se complexifier.

## Ce que l'application apporte

- Une navigation claire entre les écrans principaux
- Une interface cohérente pensée pour un usage mobile
- Des interactions fluides qui renforcent la sensation de réactivité
- Une base de projet structurée pour faciliter les évolutions futures

## Défi technique principal

Le principal enjeu a été de construire une application Flutter lisible et maintenable, en séparant proprement l'interface, la logique de navigation et les composants réutilisables. Le projet met ainsi l'accent sur la qualité d'implémentation autant que sur le rendu visuel.
