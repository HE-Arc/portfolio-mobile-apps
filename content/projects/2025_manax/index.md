Manax est un lecteur mobile connecté à une API dédiée, conçu pour offrir une expérience de lecture fluide de mangas, BD et manhwas.

Les solutions de lecture existantes sont souvent fragmentées, peu personnalisables ou dépendantes de plateformes fermées. Le projet vise à proposer une application mobile plus maîtrisée, capable d'exploiter une API personnalisée.

## Ce que l'application apporte

- Une connexion à une API dédiée pour récupérer les contenus
- Une bibliothèque centralisée de séries et chapitres
- Une lecture fluide pensée pour le mobile
- Le suivi de progression dans les contenus lus
- Des options de personnalisation visuelle

## Défi technique principal

Le principal enjeu a été d'intégrer proprement un frontend mobile à un backend existant, tout en optimisant navigation, chargement des données et confort de lecture. Le projet met en valeur la capacité à relier expérience utilisateur et intégration API.
